# Technical Competency Map

English portfolio section at `/competency-map/`, linked from the main navigation as **competencies**.

- `index.html`, `map.css`, `map.js` — static page that renders `data.json`; no build step
- `data.json` — publication-safe, generalized project descriptions. It is generated from a private source;
  do not hand-add internal figures, cost data, internal tool names or detailed counting rules here
- `fonts/` — self-hosted DM Sans / DM Mono / DM Serif Display (same families as the homepage; SIL OFL 1.1)

Personal learning features (self-assessment, evidence tracking, gap analysis, roadmap) are not part of
this public site; they live in a separate private repository.
